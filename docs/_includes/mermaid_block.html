{%- comment -%} mermaid_block.html — render a Mermaid diagram with an accessible ASCII fallback. Why this exists --------------- Mermaid diagrams render client-side via mermaid.min.js (lazy-loaded only on pages that contain a `.mermaid` element — see assets/js/mermaid-loader.js). When JavaScript is disabled, blocked, or fails to load, users still need access to the diagram's information. The `
` element below carries an ASCII/text equivalent that is visible to screen readers, search engines, and noscript clients regardless of JS state. Usage ----- {% capture diagram %}flowchart LR A[Core] --> B[ModuleManager] B --> C[Modules] {% endcapture %} {% capture ascii %} Core -> ModuleManager -> Modules {% endcapture %} {% include mermaid_block.html diagram=diagram ascii=ascii %} Parameters ---------- include.diagram — Mermaid source (multi-line, leading whitespace matters for Mermaid's parser; pass via {% capture %}). include.ascii — Plain-text fallback rendered inside
. Requirements: 3.1, 8.5 {%- endcomment -%}
