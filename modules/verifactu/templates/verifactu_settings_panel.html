Event log (registro de eventos)

While invoices are not sent to the AEAT (VERIFACTU_MODE no_verifactu, now {{ mode }}), the app keeps a chained log of events as Orden HAC/1177/2024, artículo 9 requires: start and end of operation, anomaly checks, backup restores, exports and a summary every six hours. Each event names the system below. Changing a value applies to the next events; earlier events keep the values they were made with.

Empty: you, the owner, as producer of the system you run for your own invoices. Whoever produces the software signs the declaración responsable (artículo 15) — check with your adviser who that is for your installation.

Version recorded: {{ system.version }}. The installation number was made when the log started; change it only to match a number you already declared.
